# typecho-extensions

自己的一些 Typecho 插件。

## 插件列表

| 插件 | 简介 |
| --- | --- |
| [AISummary](./AISummary) | 使用兼容 OpenAI 的接口生成并展示文章摘要 |
| [CommentHelper](./CommentHelper) | 评论通知与 AI 辅助审核 |
| [SendMail](./SendMail) | 评论回复邮件通知 |
| [ServerChan](./ServerChan) | 通过 Server 酱发送通知 |
| [TypechoMcp](./TypechoMcp) | 将 Typecho 文章、附件和 Handsome 主题字段开放为安全的 MCP 工具 |
